# ربات تلگرام سیگنال طلا — نسخه آزمایشی

این پروژه یک ربات تلگرام قابل اجراست که با دریافت داده ۵ دقیقه‌ای از Yahoo Finance، سیگنال‌های آزمایشی BUY/SELL تولید می‌کند. **ربات معامله باز نمی‌کند.**

## محدودیت‌های مهم
- نماد پیش‌فرض `GC=F` قرارداد آتی طلای COMEX است؛ **قیمت دقیق XAUUSD بروکر شما نیست**.
- داده‌های درون‌روزی Yahoo ممکن است تأخیر داشته باشند، محدود یا موقتاً قطع شوند.
- استراتژی EMA50/EMA200 + RSI + شکست ۱۰ کندل + ATR یک نمونه اولیه است؛ بک‌تست مستقل و وین‌ریت اثبات‌شده ندارد.
- ابتدا فقط در حالت آزمایشی استفاده کنید. هیچ درصد برد یا سودی تضمین نمی‌شود.

## راه‌اندازی اولیه
1. در تلگرام به `@BotFather` بروید و `/newbot` را ارسال کنید.
2. نام و username ربات را انتخاب کنید و توکن را دریافت کنید. توکن را محرمانه نگه دارید؛ در این فایل یا چت عمومی قرار ندهید.
3. این پروژه باید روی یک محیطی که پیوسته آنلاین است اجرا شود: VPS، سرور ابری یا کامپیوتر. **اجرای پیوسته صرفاً با اپ تلگرام گوشی ممکن نیست.**
4. Python 3.10 یا جدیدتر نصب کنید.
5. در پوشه پروژه اجرا کنید:
   ```bash
   pip install -r requirements.txt
   ```
6. توکن را به‌صورت متغیر محیطی تنظیم کنید، نه داخل کد.

### Windows PowerShell
```powershell
$env:TELEGRAM_BOT_TOKEN="توکن_خودت"
python bot.py
```

### Linux / VPS
```bash
export TELEGRAM_BOT_TOKEN="توکن_خودت"
python bot.py
```

سپس در تلگرام به username ربات خود بروید و `/start` را بزنید. دستورهای `/status`، `/latest`، `/help` و `/stop` نیز در دسترس‌اند.

## متغیرهای اختیاری
- `POLL_SECONDS`: فاصله بررسی، پیش‌فرض 60 ثانیه.
- `YAHOO_SYMBOL`: نماد Yahoo، پیش‌فرض `GC=F`.
- `SUBSCRIBERS_FILE` و `STATE_FILE`: محل ذخیره اشتراک‌ها و وضعیت.

## برای دریافت سیگنال دقیق‌تر مطابق بروکر
برای استفاده جدی باید منبع داده قابل اعتماد و مجاز برای نماد دقیق بروکر (مثل XAUUSD یا GOLD) متصل شود و سیگنال‌ها با اسپرد، لغزش و ساعات معاملاتی همان بروکر بک‌تست شوند.
